## 🛠️ Development & Command Rules

### Dev Server Command Strategy
When starting the dev server, always use background mode:

```bash
astro dev --background
```

Manage the background server using the built-in Astro CLI tools:
- Check server status: `astro dev status`
- Tail server logs: `astro dev logs`
- Stop server: `astro dev stop`
