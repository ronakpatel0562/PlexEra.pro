# PlexEra — Technical Talent Acquisition & IT Consulting Platform

**PlexEra** is a high-converting web application for technical talent placement, strategic IT consulting, DevOps pipeline automation, and enterprise digital transformation.

Built on **Astro** for rapid speed, optimal SEO, and component flexibility, following the **Vercel Geist Design System** (stark ink/canvas aesthetic, tightly tracked display typography, mono eyebrows, and vibrant hero mesh gradients).

---

## 🚀 Quick Start

### Prerequisites
- **Node.js**: `>= 22.12.0`
- **Package Manager**: `npm`

### Installation & Development
```bash
# 1. Install dependencies
npm install

# 2. Start local development server (foreground)
npm run dev

# 3. Or start local dev server in background (recommended for multi-tasking AI agents)
npx astro dev --background
```

The application will be accessible at `http://localhost:4321`.

---

## 🧞 Available Scripts

| Command | Action |
| :--- | :--- |
| `npm run dev` | Starts local dev server at `localhost:4321` |
| `npm run build` | Compiles production bundle to `./dist/` |
| `npm run preview` | Previews production build locally |
| `npx astro dev --background` | Runs Astro dev server as a background process |
| `npx astro dev status` | Checks background dev server status |
| `npx astro dev logs` | Displays background dev server log output |
| `npx astro dev stop` | Stops the background dev server |
